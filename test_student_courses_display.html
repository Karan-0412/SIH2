📋 Common Issues & Solutions

Issue 1: "No Courses Assigned" message

Cause: No courses have students assigned to them

Solution: Run the SQL fix script to assign students to courses

Issue 2: RLS (Row Level Security) blocking access

Cause: Database policies preventing student access

Solution: The fix script creates permissive policies

Issue 3: Data type mismatch

Cause: Student IDs are UUIDs but stored as text in assigned_student_ids

Solution: The fix script handles the conversion properly

Issue 4: No courses exist

Cause: No courses have been created

Solution: The fix script creates test courses
